Misc/Decent Usable Android Flip Phone

Table of content
  • How to enable developer options
  • How to enable ADB Debugging
  • How to install APKs

This flip phone works pretty well.

It's Schok Volt Flip Model SC3218. I purchased it in 07 of 2026 from a local best buy.

The phone has a few great features which allow it do to most things other phones can

  1. It runs Android 8.0, making it compatible with Tailscale. Android 8 contains the androidx.security:security-crypto library which some apps rely on now.

  2. Developer Mode can be enabled

  3. ADB Debugging can be enabled

  4. Sideloading APKs is allowed

How to enable developer options

  1. Open the "Tools and Settings" app

  2. Click "Lock Control 2.0"

  3. Click "System Control"

  4. Click "Allow developer mode". While you are here, enable the Virtual Mouse if you haven't already

Developer mode can then be enabled from the system settings by clicking the build number of the device 10 or so times until the developer options appear.

How to enable ADB Debugging

  1. Enter the developer options to turn it one.

  2. Ensure the USB settings are set to MTP

  3. Use a data compatible USB-C cable to test ADB. Some users report that their phones are locked at "Charging Only" in the settings. I experienced this too and found that it was because my charger was a charge only cable. That was why it perceptibly looked like the option was locked in my case.

How to install APKs

  1. Use ADB and install armeabi-v7a Android 8.0 APKS.

I had success installing some with the file manager and some with ADB from a PC. If the ADB command ever freezes then it indicates something about the application does not work with this phone. I know this phone is missing some media codecs which make some applications like "scrcpy"

Here is a list of applications that I've installed. You can copy the name of each program to find an APK online. I downloaded most of them from F-Droid and some of them from apkmirror.com.

The name of "QRCodeGenerator-de.t_dankworth.secscanqr_21.apk" would be "de.t_dankworth.secscanqr_21.apk"
